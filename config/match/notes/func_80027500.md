# func_80027500

Copies bytes from src to dst wherever a bit of a 1-bit mask is set (MSB first), stopping after n bytes. Mode 0 walks the mask linearly; otherwise the mask is read column-wise (width/8 columns, stride rows).

Matched: 0 of 64 words differ (attempt4.c). Key: `m` as u32, zero-mask test as an early `continue`, and `w >>= 3; y = stride - 1; w--;` order to schedule the sra into the delay slot.
