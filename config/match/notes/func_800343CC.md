# func_800343CC

Fills a 0x14-byte record: halfwords at 0x10/0x12 get the high/low halves of `arg1`, or `D_8005F308` twice when
`D_8005F2F8 >= 2 && arg2 == 1`; then stores `arg2` at 0, -1 at 4 and calls `func_80056760(D_8005F3E4, arg2, f10, f12)`.

Variables are defined (not extern) so they are read through `$gp`; `arg2` is `s32` (the retail compare has no
sign-extension, and the call narrows it with sll/sra). Best: `best.c` (attempt2), 28 of 32 words differ.
Attempts 1-4 (s16 vs s32 arg2, locals for the parameters) did not change it: the retail code copies `a1->a0` and `a2->a1`
at entry (before the branch), which none of the C shapes reproduced. Not matched; permuter not run.
