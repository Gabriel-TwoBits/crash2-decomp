# func_80019988

Initializes an object: clears its fields, copies the 9-word block at +0x60 and +0x18 from the parent (+0x44) when the
parent's state is 1 (else zeroes it with 0x1000 scale defaults), clears +0x18 for animations 4-5 and 0x1D. In mode 3 it
looks up a D_8006759C entry, calls func_80014260, fills fields, reads a u16 frame and calls func_8001C340.
Returns -0xE, -0x1B (no frame) or -0xFF (func_8001C340 below -0xFE).

Attempt 1 first try: 500 of 500 trials agree on seed 0 and seed 1. Saved as equivalent.c.
