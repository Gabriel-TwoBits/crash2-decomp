# func_80012010

Maps a 6-bit index (`(arg0 >> 1) & 0x3F`, logical shift) to a code: looks up a character in the byte table `D_8005B198`
and switches on it (`'A'`..`'Z'`, 18 letters mapped to 1..0x15, anything else returns 0).

- The jump table `jtbl_80010068` indexes `ch - 'A'`; the case values were read from it.
- The order of the `case` labels in the source sets the order of the code blocks: it follows the target's block
  addresses (V, S, G, W, T, L, Z, C, A, O, M, I, N, P, U, B, D, X), not the letter order.
- `arg0` is `s32` (prototype in `game.h`), so the shift needs a `(u32)` cast to get `srl`.

Attempts: 1 (cases in letter order) 17 of 55 words differ; 2 (cases in block-address order) 0 of 55. Matched.
