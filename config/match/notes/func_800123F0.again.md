# Cd_ReadFile (func_800123F0)

Reads a file from the CD when `g_UseCd` is set and `arg2 == 1`: allocates a sector-rounded buffer (`Heap_Alloc`) when
`arg1 == 0` (-0xF on failure), seeks (`CdIntToPos` on `arg0[0] & 0x7FFFFF`, `CdControl(2, ...)` until it succeeds) and
reads (`CdRead`, `Cd_SyncRead(1)`), printing `D_8005F1A8` and retrying on failure; shrinks the buffer to the exact size
(`Heap_Realloc`) when the rounded size differs from `arg0[1] & 0x1FFFF`.
