# func_8001F8B4

Registers a 16-bit key in the table `D_8006935C` (zero-terminated u16 array). The key is `(arg0 >> 8) | (D_8006759C->unk_8 << 9)`.
Does nothing when bit 0x2000 of `D_800608CC->unk_10->unk_29C` is set. Otherwise scans the table: returns if the key is
already present; remembers the last slot holding 1 (free marker); at the terminator, writes the key to that slot, or to the
terminator itself when none was seen.

m2c's draft stepped the pointer by 2 u16 elements; the assembly steps 2 bytes (one element).

Result: 500 of 500 trials agree on seeds 0 and 1 (about 400 per seed end in the same exception, compared by calls only).
