# func_800260F4

Script-command dispatcher: `arg0[0]` selects the command (0x0 to 0x900), operands follow as words (most `>> 8`).
Sets the level, changes it via func_80022224/func_80023154, sets/clears D_8005B9E4 flags, writes the 12-byte entry
tables at D_8005B9E8 and D_8005B9F4, starts/stops the D_8005BA00..BA10 timer, and calls printf for an unknown command.

- Case 0x900 is a no-op (missing from m2c's draft). `earlier.c` was the base; its pointer arithmetic was kept, with the case values named.
- Result: 2000 of 2000 trials agree (seed 0), 500 of 500 (seed 1). Nothing disagrees.
