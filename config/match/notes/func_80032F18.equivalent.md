# func_80032F18

Command dispatcher over the 0x18 entries of `D_8005F4EC` (0x50 bytes each) plus the shared state `D_8005FC84`.
`arg0` selects the target (0 = shared state, -1 = entry whose key is `arg3`, -2 = every entry, >0 = entry with that id);
`arg1 & 0x0FFFFFFF` is the command (0..14, jump table), its top bits set state flags 1/2/4. It returns early only for
queries (commands 13 and 14), and tells `func_800518B8` which slots changed (bit mask) after position/scale updates.
Gated by `D_8006CB94 & 0x1000` or `arg3->flags & 0x100000`.
