# func_8001E544

Moves an angle (12-bit) `arg0` toward `arg1` by a step of `arg2 * min(D_80063450->0x14, 0x66) / 1024`
(division truncating toward zero). The signed 12-bit difference is `diff`. If `diff` is 0, or the step reaches
it (`|diff| < |step|` with the step in the same direction as `diff`), the result is `arg1` and, when `arg3`
is non-null, bit 0x800 of `arg3->0xA8` is set. Otherwise the result is `(arg0 + step) & 0xFFF`.
