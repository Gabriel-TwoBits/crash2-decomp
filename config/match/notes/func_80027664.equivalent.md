# func_80027664

Calls func_80014260(arg0, 1, 1) for a list (count at +0xC, entry pointers from +0x10). Scans the entries by the top two
bits of their first byte: tag 0 keeps the last such entry as the header, tag 2 is counted. Without a header or a count it
returns 0. Otherwise it calls func_800277A8 with the width (bytes 1-2), height (byte 3 low 5 bits and byte 4), depth
(byte 3 high 3 bits >> 3) and the flag (byte 0 bit 0). On a non-null result it sets +0 = -0x100, +0x14 = 0,
+4 = count << 8, +0x50 = list, +0x4C = *arg0; with the flag set it also stores the result in D_80069358 and calls
func_80026EF4.
