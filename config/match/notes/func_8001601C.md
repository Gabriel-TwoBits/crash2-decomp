# func_8001601C

Sets a default draw environment (0,0,1024x512), sets its flag byte at +0x17, applies it with PutDrawEnv, then builds a
fill primitive (len 3, code 2, rgb 0, xy 0,0, wh 0x3FF x 0x1FF) and draws it with DrawPrim.

First attempt matched: 0 of 37 words differ. The environment is a `u8[0x60]` buffer (sets the frame size and the
offset of the primitive at 0x78); the primitive is a local 16-byte struct.
