# func_80023E60

Walks a path of `arg1` 16-byte nodes (`unk4` segment id, `unk8` position, `unkC` direction 1/2). Computes the path length from
the first node to the last (segment lengths from `func_800322C0(seg, 0x4B, 0, 2)`), scales it by `arg3/256` (or, for
`arg3 < 0`, by the `func_800321D4` speed, clamped at 0x7D000, and returns the last node when the scaled length is under 9),
walks that distance from the first node and writes the resulting node to `*arg2`.

`earlier.c` with the signature kept as `s32 *` (cast inside) and named constants. 500 of 500 trials agree on seeds 0 and 1;
about 190 of each are trials where both sides take the same exception, which are not compared on memory.
