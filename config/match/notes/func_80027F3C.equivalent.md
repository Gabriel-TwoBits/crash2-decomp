# func_80027F3C notes

Octree-style swept-box walk. `arg1` is a node reference: bit 0 set or offset 0 is a leaf (`node` = the value itself), otherwise
an internal node at `arg0 + offset` holding up to 8 `u16` child references.

- Internal node: per axis, `arg5 < s16 depth[axis]` (at `arg0+0x1E/0x20/0x22`) splits the box in two halves (size / 2).
  Children are visited x-major, then y, then z; the child index increases by one per visit. A child is recursed into
  (depth + 1) only when `child < point` and `child + size >= point` on every axis; the first nonzero result is returned.
- Leaf with `node == 0`: `t` = min over axes of `((edge - pos) << 8) / vel`, then `pos += ((t + 0x100) * vel) >> 8`; returns 0.
- Leaf with `node != 0`: picks the axis (x, then z, then y, with `|vel|` tie-breaks; y never updates the time) whose step
  back is the latest, negates its velocity and sets `pos` to the box edge; returns `node`.

Remaining disagreements: in the blocked path the retail code reads `$t0` (the chosen axis) uninitialised when all three
`vel` components are zero; the result then depends on the caller's leftover `$t0`. The C treats that case as no axis chosen.
