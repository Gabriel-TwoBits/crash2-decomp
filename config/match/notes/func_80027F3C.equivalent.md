# func_80027F3C notes

Octree-style swept-box walk. `arg1` is a node reference: bit 0 set or offset 0 is a leaf (`node` = the value itself), otherwise
an internal node at `arg0 + offset` holding up to 8 `u16` child references.

- Internal node: per axis, `arg5 < s16 depth[axis]` (at `arg0+0x1E/0x20/0x22`) splits the box in two halves (size / 2),
  otherwise one child of full size. Children are visited x-major, then y, then z; child index increases by one per
  visit. A child is recursed into (box = {pos, size}, depth + 1) only when `child < point` on every axis and
  `child + size >= point`; the first nonzero result is returned, otherwise 0.
- Leaf with `node == 0` (free): `t` = min over axes of `((edge - pos) << 8) / vel`, then `pos += ((t + 0x100) * vel) >> 8`; returns 0.
- Leaf with `node != 0` (blocked): picks the axis (x, then z, then y, with `|vel|` tie-breaks) whose step back is the
  latest, negates its velocity and sets `pos` to the box edge; returns `node`.

Attempts: attempt1.c (= best.c). 500/500 on seed 0, 497/500 on seed 1, 2995/3000 over 3000 trials.

Remaining disagreements: in the blocked path the retail code reads `$t0` (the chosen axis) without initialising it when
no axis is selected (all three `vel` components zero). The retail result then depends on the caller's leftover `$t0`
(0, 1 or 2 selects that axis's negate-and-clamp). The C uses `AXIS_NONE` (no change) for that case, so trials whose
leftover register selects an axis disagree.
