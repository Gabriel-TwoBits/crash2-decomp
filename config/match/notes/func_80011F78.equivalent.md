# func_80011F78

Packs the first 5 characters of a string into a 32-bit key: each character becomes its index (0..63) in the
table `D_8005B198` (0x3E when absent), 6 bits per character. A NUL ends the string early and the remaining slots
are filled with 0x3E. The result is `(packed << 1) | 1`.
