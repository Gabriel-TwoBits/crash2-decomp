# func_8001148C

First-fit allocator over a chunked heap of 4-byte headers (bit 0 set = free, upper bits = size in bytes, -2 = end of
chunk). Rounds the request up to 4, initialises the heap on first use (one chunk from D_8005F2A4 via func_800111B0),
then scans from D_80062BAC: exact fit is claimed, a larger block is split, a smaller one is merged with its successor
(or truncates the chunk at -2), used blocks are skipped. Two passes over the chunk list, then func_800111B0 grows the
heap; failure returns 0.

Attempt 1 (equivalent.c): 500 of 500 trials agree on seeds 0 and 1. The only bug on the way was the merge-skip case,
where the successor header address (not +4) becomes the cursor.
