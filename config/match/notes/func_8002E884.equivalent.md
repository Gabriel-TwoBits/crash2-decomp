# func_8002E884 notes

Finds the nearest allowed point to a position on a row/column cell map (`func_80014260` result `->0x10`), writing
the correction into `arg1[0]` and `arg1[2]`. Cell words: bit 0x2000 solid, bits 0x1FFF/0xC000 edge height and
slope for the low half, the same again in the high half.

- Early checks: scans rows row-1..row+1 for the first/last open row next to a solid one (returns when a solid row
  is met and `arg2 == 0`, or none is open); returns without writing when the position is already clear of the edges.
- Otherwise scores the clamped point of each open row (nearest-edge rows with margin `arg3`) and two slope
  candidates per row, keeping the smallest squared distance; writes the correction if any was found.
- `key[4]`: `func_80014260` receives a frame address and the harness compares 4 words of it; the extra words keep
  the compiler from spilling into them.

Final: attempt2.c, equivalent.c. 500/500 on seeds 0 and 1, 3000/3000 on seed 2. Most trials end in the same
exception (random map pointer), so the branch coverage comes from mirroring the assembly branch by branch.
