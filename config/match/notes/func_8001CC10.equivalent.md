# func_8001CC10 notes

Runs script command `id` on object `obj` (arg1); `self` (arg0), when non-null, gets a status word at +0xD4.
With a pending script (+0xCC) it pushes `id` and `args`, calls func_8001C620/func_8003A014 and keeps the result;
a result >= -0xFE returns at once, -0x1A (or a lower one) continues. Otherwise `id >> 8` indexes the bank;
bit 0x8000 starts a script (args pushed, returns func_8003A014's result), else func_8001C340 runs when the
flag mask allows. Returns -0xFF unless a script ran.

Started from `earlier.c`; `s3` as `s32` (retail reads it with `lw` from the stack out-buffer), `*stack++` on `s32 *`
(m2c's +4 scaling was wrong), `-0xFF` returns split by the retail's two exits (`self->fD4 = 0` only on a failed flag test).
Result: 500 of 500 trials agree on both seeds.
