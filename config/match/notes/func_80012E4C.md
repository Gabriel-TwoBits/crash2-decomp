# func_80012E4C

Starts a CD seek: if `D_8005F1A4` is set, `D_80067FB4[0]` is 0 and `CdSync(1, 0)` returns 0, converts the 24-bit
sector field (`& 0x7FFFFF`) of entry `arg0` (12-byte stride, `D_80069034`) with `CdIntToPos` and issues `CdControlF(0x15, pos)`.

Control flow, frame and loads match. Final count: 8 of 33 words differ (best.c).

Differs: the retail code computes the index (`arg0 * 12`) and loads the array word first, then builds the 0x7FFFFF mask
(`lui`/`ori`) after the load; the compiled code builds the mask first. Tried: int array with `arg0 * 3`, 12-byte struct,
`v & mask` through a temporary, swapped operand order, a separate `pos` statement. None changed the scheduling.
