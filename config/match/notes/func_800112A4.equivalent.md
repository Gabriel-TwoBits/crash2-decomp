# func_800112A4

Heap block resize/coalesce. `arg0` is a payload pointer, the header word is at `arg0 - 4`, `arg1` the requested size (rounded up to 4).
Bit 0 of a header marks a free block, `-2` is the end marker. Returns 0 on an end-marker header. Otherwise it merges following free
blocks until the size fits (extending into the unused tail when it reaches the end marker and room remains below `D_8005F2B4`, moving `D_8005F2A4`).
Then it splits off the remainder as a new free block, or returns 0 if the block is still too small, else `arg0`.

Result: 500 of 500 trials agree on seeds 0 and 1 (most by the same exception).
