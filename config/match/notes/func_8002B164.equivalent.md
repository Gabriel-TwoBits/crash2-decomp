# func_8002B164 notes

Builds a query box (±0x9600 in x/z, y range from arg2[1] plus the object's height or 0x29900) in arg3+0x1020, calls
func_8002A3B0 and func_8002A554 for two ground hits and a third result, then derives a floor (arg3+0x1038), a
ceiling limit (*arg4) and a clamped y written back to arg2[1], with flag updates on arg0+0xA8/0x110/0x114.

Written from the assembly following m2c's draft, with named constants. Branch-for-branch, including the no-hit
sentinel 0xC4653601 paths. The asm leaves s2 in v0 at return; the declared type is void, so it is not reproduced.

Result: attempt1.c = equivalent.c, 500 of 500 trials agree on seeds 0 and 1 (about half end in the same exception,
where memory is not compared; the rest compare calls and memory).
