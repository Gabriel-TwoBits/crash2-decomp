# func_800157A0

Shutdown routine: if D_8005F1A4 is set, stops the CD (CdControl(8,0,0), StopCallback); then func_80036304, StopPAD,
ResetGraph(3), and inside a critical section StopRCnt(0xF2000002), DisableEvent/CloseEvent on the event in D_8005F3DC.
Returns -0xFF.

Result: `./score.sh match.c` reports 0 of 34 words differ.

Findings:
- m2c's draft differed only in how D_8005F3DC is addressed: retail uses `$gp`, an `extern s32` compiles to `lui`/`lw`.
- A definition with an initializer (`s32 D_8005F3DC = 1;`, small data) gives the `$gp`-relative load. A bare definition
  (common) and an `extern` do not.
- The probe only compares code words, so the definition's value is arbitrary. Integrating into src/ needs care: the
  symbol is already defined by the retail data, so the same-named definition may collide at link time (needs a
  linker-script or symbol-handling decision, not made here). D_8005F1A4 stays `extern` (retail uses `lui`).
