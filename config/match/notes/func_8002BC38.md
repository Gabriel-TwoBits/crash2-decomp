# func_8002BC38

Clamps the Y of a moving object's next position (`arg2[1]`) against a floor/ceiling height returned by
`func_8002B57C`. A flag passed to it is set when `arg0+0xA8` has bit 0x100000, all eight words at `arg0->+8` +0x4C..+0x68
have bit 0x100000, and `arg0+0x100` lacks bit 0x40000000. The result (or 0 for the sentinel 0xC4653601) goes to
`arg3+0x103C`. If within range (`ret - 1 < arg2[1] + limit`, limit 0x29900 or `arg0->+8->+0x40`) and `arg0+0xA8` bit 1
is clear, Y is clamped (smoothly via `func_8001E5FC` when `arg0+0x100 & 0x40`), `0x80` is set in `+0xA8` and a positive
`+0x88` cleared. Otherwise, with `+0x100 & 0x40`, Y is reset to `arg1[1]` (sentinel) or eased and `func_8001CC10`
is called with event 0x3300.
