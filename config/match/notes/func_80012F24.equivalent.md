# func_80012F24 notes

Computes a CD sector, destination buffer and sector count from a descriptor (`arg0`) and `arg1`, then loops until a CD read
is accepted: seek (`CdIntToPos` + `CdControlF(2)`), `CdSync` poll/block, `CdRead(count, buf, 0x80)`. Any failed step
retries from the seek. Returns -0xFF.

- With `arg0->0xA != 0`: offset `arg0->8` shifts count and buffer, sector from the table at `D_800675A0 + 0x420`.
- Otherwise: sector from `D_800675A0->0x418` plus `(arg0->0x14 >> 1) << 5`.

Final: 500 of 500 trials agree on seeds 0 and 1 (`equivalent.c`). Starts from the earlier run's C; the only change is
using the file's own `CdIntToPos`/`CdRead` prototypes (buffer typed `s32`). The position buffer is 16 bytes because the
retail frame has 4 zero words at sp+0x10.
