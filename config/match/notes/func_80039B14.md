# func_80039B14

Decodes two 12-bit operand fields of an instruction word (`arg1 >> 12` and `arg1`) for an interpreter-style object.
Each field is a register slot (`obj + 0x40 + (field & 0x1FF) * 4`) when `(field & 0xE00) == 0xE00`, a pre-decrement
stack pop (`obj->0xBC -= 4`, slot is the new pointer) when the field is `0xE1F`, or `func_80036D0C(obj, field)` otherwise.
The result is `obj->0xD4 = func_800270C4(*b, *a)`.

Not matched: best is `best.c` (= `a2.c`), 55 of 61 words differ. The control flow lines up; the difference is register
allocation: the retail code keeps `arg1` in `$s2` and the first slot pointer in `$s1`, while the compiled code puts `arg1`
in `$s1` and the pointer in `$s2` (the prologue stores and every later word shift from there).
