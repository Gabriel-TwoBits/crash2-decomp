# func_80014148

Looks up an entry (0x2C bytes) from a handle.

- Bit 1 set: only handles with top bits `10` are valid; scans the 16 entries downward from `D_80063000` for one whose
  halfword at offset 4 is 0x14 or 0x15 and whose word at 0x1C equals the handle. Returns it, else 0.
- Bit 1 clear: `idx = (handle - D_800675B4) / 0x10000` (rounded toward zero via the +0xFFFF bias); if
  `0 <= idx < D_800675B0.count`, returns `&D_800675B4 + idx * 0x2C`, else 0.

Single attempt (written from the assembly; the earlier m2c draft mis-scaled the pointer step). 500 of 500 trials agree on
seeds 0 and 1. `equivalent.c` is final; `Unk80013BD8`, its table and `Unk80014148` are copied from the file as they are.
