# func_80017380 notes

Computes a texture rectangle (`out[0..3]`) for one entry of a record. The entry pointer `p` is
`base + (arg2 >> 8) * 16 + 8` for type byte 2, or `* 24 + 12` for type 5. Any other type leaves `$s0` untouched, so
retail uses the caller's `$s0` as the entry. It calls `func_80018474(p + 4, base + 4)`, then branches on mode: 2 gives
a VRAM position and width 0x10/0x100; 1 takes min/max of three (x, y) byte pairs and scales x by the bit depth in
bits 7-8 of the halfword at `p + 0xA` (divide by 2, 4 or none).
