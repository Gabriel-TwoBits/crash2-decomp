# func_80033D10

Sets up the sound system: enables tick mode, calls func_80033C84 with a scaled D_8006CBFC, resets some globals, then
picks the reserved-voice count (0x10 default, 0x11/0x12/0xC for some values of D_8005F3EC) and passes it to SsSetReservedVoice.

- Matched: 0 of 48 words differ (attempt3.c = match.c).
- The jump table comes from rodata (jtbl_800105D0); case values are table index + 1.
- `case 1:` beside `default:` makes GCC subtract 1 instead of 2 (table starts at value 1).
- `(u8)` cast on the SsSetReservedVoice argument gives the `lbu`.
