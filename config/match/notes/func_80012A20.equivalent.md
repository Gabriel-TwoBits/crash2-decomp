# func_80012A20

Releases an object: clears `D_80067FB4[0]` if it holds the object. For state 0x14/0x15 with header kind not 1, 3 or 4,
walks the header's items, calls each item's handler from `D_8005B1EC` (stride 0x1C), stores the object's index into the
matching `D_80067590` table entry, then calls `func_80013F28`. Kinds 1/3/4 write -0x12 into `D_80067FC4[idx >> 1]`
and, like any other state, fall to setting state 1 and clearing bytes 0xE/0xF. Returns -0xFF.

Based on `earlier.c` with named constants and `unk_` fields. Result: 500 of 500 trials agree on seeds 0 and 1.
