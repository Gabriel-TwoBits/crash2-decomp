# func_80034BB8

Reads one save-file entry from the memory card. It opens `bu00:<name>` (3 tries), reads the 0x80-byte header (3 tries),
and fills slot `D_8005F264[2]` (kind, span, name, or the default name from `D_8001067C` when the kind is invalid). For a
"last entry" slot it also reads the kind-sized data blocks and 0x16 extra blocks. Every I/O step goes through
`func_800349F8`, and a failure ends the function. It then copies the slot over the following `span - 1` slots and advances
the entry index and the next-slot index. A full entry table reports error 2 and returns.

Attempts: `attempt2.c` was a straight translation (427 and 437 of 500 trials). The only differences were a stack word next to
the context passed to `func_800349F8`, which the tester dumps; the retail code leaves it untouched. `ctx[4]` gives the
frame that layout (`attempt3.c`).

Final: `equivalent.c`, 500 of 500 trials agree on seed 0 and on seed 1. Nothing disagrees.
