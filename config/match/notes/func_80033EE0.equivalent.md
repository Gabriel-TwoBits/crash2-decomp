# func_80033EE0 notes

Sequence loader/starter. Returns -1 while D_8005F308 is set. In state 1 (D_8005F39C) it waits three calls, then closes
the open SEP and releases the previous entry (D_8005F2F4). A `NONE` (0x6396347F) argument resets the state to 0. Otherwise
it loads the entry, sets state 2, and returns 0 until the seven sub-entries are ready (func_800143C0). Then it sets
state 3, opens the VAB once (SsVabFakeHead/Body, SsStart) and the SEP, and inits each of the D_8005F2F8 sequences with
func_800343CC (plus func_800528C4 when the VAB was already open).

Written from `earlier.c`, whose logic is the same; changes: the argument is `s32` (game.h) cast to a pointer,
func_800343CC takes three arguments and the file's `Unk800343CC` type, and the uninitialised 4th argument ($s5 passed
through) is dropped since the callee takes three.

Result: 500 of 500 trials agree on seeds 0 and 1 (`equivalent.c`).

`s32`, which the score accepted.
