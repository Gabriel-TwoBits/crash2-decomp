# func_8002A554 notes

Sweeps the object list (`D_8006CB6C`) with a box around `arg2` (x/z +-0x4B00, y from `arg2[1]` up to the ceiling),
calling `func_8002A8D0` per object with the best hit so far, a depth limit and the object's optional `0x9C` data.
Objects that hit and pass the flag tests are flagged `0xA8 |= 0x4000`, recorded in `arg0->unk8->unk48`, and set the
return value (`hit + 1`). The last object that hit is passed to `func_8001A710`. Returns `NO_HIT` when the list is empty
or nothing hit.

Started from `earlier.c`, which already had the right logic; only the callee declarations had to go (game.h has them)
and the `unk9C` argument needed an `s32` cast. Constants `NO_HIT` and `BOX_HALF_EXTENT` named.

Final: 500 of 500 trials agree on seeds 0 and 1. Nothing disagrees. The `(unkAC & 0x400000) == 1` test is never true
(kept as the assembly has it), so the limit is always the computed ceiling.
