# func_8001E544

Steps an angle (12-bit, 0..0xFFF) from `arg0` toward `arg1`. The step is `arg2 * min(D_80063450[5], 0x66) / 1024`
(signed division). The signed 12-bit difference `arg1 - arg0` decides the result: when it is zero, or smaller in
magnitude than the step with the same sign, the target is reached and the result is `arg1`, setting bit 0x800 of
`arg3->0xA8` when `arg3` is non-null. Otherwise the result is `(arg0 + step) & 0xFFF`.

Tried: a plain `if` rewrite and m2c's goto form (both 23-24 words differ), and the permuter for 3 minutes (best 21, not
kept in a file). Best kept: `best.c` (attempt5), 24 of 46 words differ.

Still differs: the signed difference lands in `$t0` and its absolute value in `$v1`, the reverse of the retail
registers. The retail code also returns through `$a0` (`arg0` reused as the result), so the branch layout after the
`slt` differs too. Compiling needs `0` instead of `NULL`, since `NULL` is not defined by the headers here.
