# func_800136C8 notes

Finds the best run of slots in the table at D_800675B0 (count, then 0x2C-byte entries); `*arg0` is the wanted length.
A slot extends the run when its state is 1 (free), or 0x14/0x15 with f_f <= 0 (cost += 1 + f_28); any other slot ends it.
Per start index, the longest run wins and the lowest cost breaks ties. The chosen run goes to func_80012A20 entry by entry,
`*arg0` gets its length and the start index is returned. With no run: `*arg0 = 0`, `printf(D_8005F1C8)` if arg1 != 0, return -1.

Final: equivalent.c, 1000 of 1000 trials agree (seed 0), 500 of 500 (seed 1). Trials that hit the instruction limit are not compared.
Started from earlier.c's logic, restructured into for loops with explicit else branches and named constants.
