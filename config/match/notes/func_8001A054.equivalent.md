# func_8001A054

Merges a list of keys into a table of 0xC-byte entries (key, 0, value) at D_8006302C, count in D_8005F3B8.
For each of the `arg2` words at `arg1` (walked from the last to the first), it looks for an entry whose key matches
under the mask 0xFFFF00. A match overwrites the key with the full word and stores `arg0` as the value. With no match,
a new entry is appended (value `arg0`, middle word 0, key the word) and the count is incremented.

m2c's draft stepped the source pointer by 16 bytes (`s32 *` minus 4); the assembly steps by 4 bytes.

Result: 500 of 500 trials agree on seeds 0 and 1 (`equivalent.c`).
