# func_8002DF68

Tests bit `arg0` (counted from the most significant bit) of word `arg1` in the `D_8005F3C4` array. Returns 1 when the bit is clear, 0 when it is set. Both indices must be below 32; otherwise it returns 0.

Attempt 1 was m2c's draft with named constants, a `D_8005F3C4` extern and an explicit empty `else`. It agrees on 500 of 500 trials on seed 0 and on seed 1 (some of those trials end in the same exception). Nothing still disagrees.
