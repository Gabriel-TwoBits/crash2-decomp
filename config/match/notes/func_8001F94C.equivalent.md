# func_8001F94C

Builds a key `((arg0 >> 8) | (D_8006759C->word8 << 9)) & 0xFFFF` and scans the zero-terminated u16 array `D_8006935C`
one halfword at a time (m2c stepped 4 bytes; the assembly steps 2). On the first element equal to the key it writes
1 to that element if the following halfword is nonzero, else 0, and returns. No match: nothing changes.

Attempt 1 (equivalent.c): 500 of 500 trials agree on seeds 0 and 1. Nothing disagrees.
