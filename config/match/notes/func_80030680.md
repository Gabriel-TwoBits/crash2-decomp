# func_80030680

Point-in-quad test. `arg0` is a point {x, y}, `arg1` four corners {x, y}. Rejects points outside the bounding box
(returns 0), returns 1 for a degenerate box, then collects the x of each edge crossing the scanline y = point.y
(fixed-point 12-bit interpolation) into a local `s32[8]`, bubble-sorts them, drops duplicates equal to the first value at
the start and equal to the last at the end, and returns 1 when point.x lies inside one of the [x0, x1] pairs (or equals
the single crossing).

## Tried

- attempt1: plain draft, 165 of 202 words.
- attempt2/3: the crossing loop with one shared `s++; n++` tail and `goto next` for the misses; pointer `q` to the next
  corner; `x0 = x1, y0 = y1` in the `for` increment: 59 words, 18 without a counterpart.
- attempt5: n == 1 test inside an `if/else` around the pair loop (fixes the `xor/sltiu` setcc): 72 words but
  17 without a counterpart.
- attempt8 (best.c): bubble sort over one pointer `a` with `a[0]`/`a[1]`: 72 words, 16 without a counterpart.

## Still differs

- The trailing duplicate loop: the retail loads the last value once (`lw 4($v1)` before the loop) and tests `*p` at the
  top with `n < 3` at the bottom; every form tried (do/while, while with break, `last` hoisted by hand) gets rotated by
  GCC's loop pass.
- Register swaps: maxX/pointer in the bounds loop (`$a3`/`$t0`), the interpolated value lands in `$v0` instead of `$a2`,
  and the bubble sort's `swapped`/`a`/`b` are rotated across `$a1`/`$a2`/`$a3`.
