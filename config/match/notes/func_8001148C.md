# func_8001148C

First-fit heap allocator over a block list. Sizes are rounded up to 4 bytes; each block has a header word (size, bit 0 set
when free; -2 ends the list). On the first call it initialises the list from `D_8005F2A4` and calls `func_800111B0`.
The loop walks from `D_80062BAC`: an exact fit is claimed, a larger free block is split, a block followed by free blocks
is merged, and at the end of the list (second pass) `func_800111B0` is called again. Returns the block address + 4, or 0.

Not matched: best is `best.c`, 75 of 141 words differ.
