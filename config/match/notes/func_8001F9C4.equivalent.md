# func_8001F9C4 notes

Menu-state tick: if the save magic is already set, clears a field and returns -0xFF. Otherwise it picks a slot (from D_8006CD7C, or by searching the D_8005B914 table for a key derived from the input state), wraps it, clears D_8006B1C4, runs the setup calls, stores the entry, calls func_80014260/func_800200A8/func_800143C0, returns -0xFF.

m2c stepped the table pointer by 4 words; the asm steps 1 word. A state mismatch with D_8005F3EC is an infinite loop, kept.
