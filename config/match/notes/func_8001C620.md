# func_8001C620

Pushes three words onto a command buffer whose write pointer is at +0xBC of the first argument: `arg2`, the word at +0xC0,
and a packed word (low half `cur - arg1*4 - 0x40 - base`, high half `prev - 0x40 - base`, where `cur` is the old write
pointer and `prev` the value previously at +0xC4). Stores `cur` to +0xC4, advances +0xBC by 4 after each push, returns -0xFF.
