# func_80027C00

Run-length decoder. Reads a signed control byte from `src`: negative copies `-c` literal bytes (`-0x80` takes a big-endian
16-bit count instead); positive repeats the next byte `c + 1` times; zero reads a 16-bit count (zero ends the stream) and
repeats the next byte `count + 1` times. Returns the number of bytes written.

Matched, 0 of 52 words differ (`match.c`, 3 attempts). Placing the positive case first in an `if (c >= 0)` fixed the layout;
reading the high byte of the 16-bit count into a separate `s32` fixed the register order.
