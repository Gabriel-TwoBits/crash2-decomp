# Zone_IsLinked

Searches the table at `arg0->0x10 + 0x194` (one word per slot, count at `+0x190`) for `arg1->4`. A slot with bit 0 set is
compared directly with the key; otherwise it is a pointer whose word at +4 is compared. Returns 1 on a hit, 0 otherwise.

Matched: 0 of 31 words differ (`match.c`). Started from `earlier.c` (3 differ). The odd-slot path with `i++` after the
`return 1` test and the `do { return 1; } while (0);` wrapper on the pointer path (found by decomp-permuter) gives the
target's `beq`/`ori` and `j`/`addiu` ordering. The `pad[2]` local sets the 8-byte frame.
