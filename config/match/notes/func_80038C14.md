# func_80038C14

Decodes two 12-bit operands packed in `arg1` (bits 12-23 and 0-11) into pointers, then stores
`func_80032B7C(obj, b, *(s16 *)a)` at `obj + 0x12C`. Operand decoding (a GOOL-style operand):
if `(idx & 0xE00) == 0xE00`, `0xE1F` pops the stack pointer at `obj + 0xBC` (pre-decrement by
4), otherwise it is `&obj->regs[idx & 0x1FF]` with `regs` at `obj + 0x40`; any other value goes
through `func_80036D0C(obj, idx)`.
