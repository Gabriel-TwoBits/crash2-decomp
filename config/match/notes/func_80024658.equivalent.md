# func_80024658 notes

Finds the best of several candidate entries for a slot-1 query. It types the slot entry `arg0 + (arg5 - 1) * 16` via
func_800321D4/func_800242F8, scores it with func_800253B0/80024A48 (slot 1) or func_800254D4/80024B6C (other slots, by
`arg3`) and stores the result word at entry+8. For slot 1 it copies entry 0 into entry 1 (words 0, 1, 3) and returns 2;
func_800267C4 then lists alternative entries, each scored directly (same type) or via func_8002433C, and the lowest
non-negative score is copied to `arg0[4..7]`. `arg3` is overwritten by func_8002433C's result in the loop, as in the assembly.

arguments and type/slot at the retail frame offsets (0xA0, 0xA8, 0xB0, 0xB8, 0xC0), so a func_800267C4 count past the
7 list slots reads the same words and func_8002433C's frame-address arguments show the same neighbours.
