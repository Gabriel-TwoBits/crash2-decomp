# func_80025D18

Checks the player position against three optional range entries (types 0x1E3, 0x1E2, 0x1E4) fetched with `func_80031AE8`.
The 0x1E3 entry bounds Y directly; 0x1E2 and 0x1E4 bound X and Z after rotating the position by `-D_80060828`.
A range with max < min is ignored (0x1E3 skipped, others dropped). Outside a range, `func_80025FDC(0, &value << 8)` is called.

Attempt 1 (490/500) read `max` before `min`, so a fault address differed; attempt 2 reads `min` then `max` first: 500/500 on seeds 0 and 1.
The X and Z limits share the locals xMin/xMax with the Y entry, as the assembly shares s5/s6; they are only read when the X entry is live.
