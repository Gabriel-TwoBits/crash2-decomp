# func_80027980
If arg0->unk_8 is nonzero, sets arg0->unk_C = 1, then walks the 0x54-byte entries at D_80069338 from index D_80069334[0]-1 down to 0.
A entry with state (+8) == 1 and flag (+0xC) == 1 is cleared and its size (+0x10) moves from D_80069334+0x10 to +0xC; state 1 with another flag stops the walk.
Result: 500 of 500 trials agree on seeds 0 and 1 (equivalent.c).
