# func_8001B83C

Text layout/draw routine. It walks a string and handles `~` commands (`p` palette skip, `c` colour flag, `s` x/y
advance size, `x`/`y` offsets, `l`, `%`, `n` line breaks), `\n` newline and the `&` terminator. For each glyph (20-byte
entries below the font) it computes the box, tracks the max right edge (the return value), calls func_80018474 and
func_800186D8, and optionally accumulates bounds drawn with func_8001856C at the end.

Tried: one attempt (attempt1.c), written from the assembly. Result: 500 of 500 trials agree on seeds 0 and 1, and
2000 of 2000 with `--trials 2000`. About 45% of trials end in the same exception (calls compared, not memory), so the
tester covers those paths less than a reading of the assembly does.

Nothing still disagrees.
