# func_800200A8

Selects the active object (arg0) and screen/segment (arg1) at position arg2 (flags arg3), tracking which parts changed
(object, target, position, segment, field 0x48). On a change it unloads/reloads the object's active entries, streams the
segments between the old and new index (or reloads from either end when far), updates the D_800608xx state, copies a
9-word block, calls func_80023D7C and updates SetGeomScreen if the value changed. Afterwards it sets up D_8005F38C once.

Final: 500 of 500 trials on seeds 0 and 1.

Declared-but-wrong prototypes (game.h or another file) are called through casts to the true signature:
func_8001A014(s32), func_800221DC(s32), func_80026A08 (5th stack arg = 1), func_80023D7C (returns s32).
The "not found" short lookups store 0xFFFF (ori), not -1. Many trials end in the same exception, so deep paths see less coverage.
