# func_8002CB68

Clears or sets a column-masked bit range in a 32-row table of words at `D_8005F3C4`: the mask comes from the clamped x
range (`arg0`, `arg2`), the rows from `arg1`..`arg3` (clamped to 0..32), and `arg4` selects set (non-zero) or clear.

Matched on the second attempt: early returns for the empty ranges, `(s32)0x80000000 >> arg0` (signed shift), and the clear
branch as `mask = ~mask; while (x < end)`, which lets the scheduler fill the delay slot. Final count: 0 of 58 words differ.
