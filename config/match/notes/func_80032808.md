# func_80032808

Releases the slots of a 0x50-byte entry table (`D_8005F4EC`, 0x18 entries) that belong to `arg0`, starting at index `D_8005F304`.
For each entry with flag bit 8 set and `key` (+0xC) equal to `arg0`: sets `D_8005F244 = 0x3C`, calls `func_80032F18(entry[0], 0x40000000, &zero, key)`, then clears `key` and the byte at +0x1D.

Result: `0 of 51 words differ` (`match.c`).

- `D_8005F244` and `D_8005F304` must be defined (with an initialiser) in the file for the compiler to address them through `$gp`; as `extern` they compile to `lui`/`lw`. The definitions are only a probe device and clash with the real symbols when linked.
- A plain version leaves 4 words: the `sw $zero, 0x10($sp)` is scheduled before the loads instead of in the `jal` delay slot.
- decomp-permuter closed it in under a minute by duplicating the body under a dummy `if (i)` / `else`; the duplicate branches are what restores the scheduling. Not a faithful reconstruction of the original source.
