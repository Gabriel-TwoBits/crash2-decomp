# func_80035444 notes

Save-card step of the memory-card state machine (modes 6 = erase old file, 7 = create, 8 = rewrite). It finds the current
slot entry in the `D_8005F264` block, builds the file path (existing name, or a new `serial` name capped at 99),
erases or opens it with up to 3 tries per call (each followed by `func_800349F8` with a context block `{&fd, -, &D_8005F314,
&D_8005F318, path}`), then writes the header block, three icon blocks and 22 data blocks of 0x80 bytes.

Tried: m2c draft cleaned into plain C (attempt1), which disagreed only in the callee context's frame address (the
frame was 8 bytes larger). Reloading `D_8005F264` at each use, as the retail does, instead of keeping it in a local
removed the extra saved register (attempt2).

Final: 500 of 500 trials agree on seeds 0 and 1. The m2c outer loop of one iteration is written as a single pass.
