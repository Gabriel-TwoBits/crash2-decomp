# func_80032B7C

Starts a sound voice. Returns 0 when sound is off or neither `D_8006CB94 & 0x1000` nor the object's flag `0x100000` (offset 0x100) is set, and -1 when no voice is free (`func_800328D4`) or `func_80032A98` returns -0xE.

Otherwise it:
- copies the 0x4C-byte template `D_8005FC84` into the `D_8005F4EC` entry of the voice;
- scales the volume (`arg2 * D_8005F2E8 >> 14`) into entry+0x1E, and computes the fade step (entry+0x44) when flag 0x40 is set;
- stores the object (`arg0`) and its position, with `func_8001EC2C` converting it;
- builds the `func_800518B8` command block on the stack: volume clamped to 0..0x3FFF for object type 6 or 7, otherwise the 4 bytes from `func_8003264C`, read unaligned;
- sets reverb, starts the voice with `func_80051078` when flags `0x8010` are clear, and bumps the `D_8005F2E0` serial number.

The retail code passes a third argument (`arg0`) to `func_80032A98`; the callee ignores it, so the C calls it with 2.

The table entry is read bytewise, `p[2..3]` first, to match the retail fault address on unmapped pointers.
