# func_8002433C

Side test of a point (`arg1`) against an object (`arg0`: +4 object, +8 angle). Calls `func_80023B04(arg0, &lo, &hi)`
(limits stored through `arg2`/`arg3` when non-null), builds the offset vector (camera globals when the object is
`D_800608D4[0]`, else object position plus a `func_80031AE8` entry, `<< 8`), rotates it by `-angle2` (mode 1 adds the
terms, other modes subtract; mode 2 skips rotation and uses `-dy`), and returns 1 above `hi`, else `-(r < lo)`.

The earlier run's draft called `func_80023B04` with two arguments; the assembly passes `arg0` through, which fixed the
declaration conflict.

Final: 500 of 500 trials agree on seeds 0 and 1 (most end in the same exception, so the paths behind it are checked
by reading against target.s, not by the trials).
