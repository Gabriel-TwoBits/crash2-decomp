# func_80031AE8

Looks up an animation-like entry by key in a chain of lists (binary search over 8-byte entries at list+0x10, next list
at +8) and, per mode (`arg5`), returns a pointer into the entry's data or writes an interpolated/copied frame to `arg6`:
- Entry layout: `unk_02` = offset to per-frame size table (flag 0x40, else one shared size), time table (flag 0x20),
  then 4-aligned data; `unk_05` = element size; flags & 0x1F = element type.
- Mode 2: frame index = `arg2`. Modes 0/1: frame found by binary search of `arg2 >> 8` in the time table (mode 1 needs
  an exact time). Other modes: interpolate between frame and the next (types 1/17 byte, 2/18 half, 3-5/19 word, 6 three
  halfs, 7 three words); plain copy at the last frame, on differing sizes or zero time delta.
- Returns 0 when not found / out of range.

Tried: one attempt (`attempt2.c`, copied to `equivalent.c`). Result: 500 of 500 on seeds 0 and 1, 3000 of 3000 on seed 7;
about three quarters of the trials end in the same memory exception (not compared in memory).
