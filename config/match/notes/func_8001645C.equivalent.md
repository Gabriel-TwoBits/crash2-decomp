# func_8001645C notes

Per-frame display flip: bumps the frame counter, steps the fade value (D_8006CD18) and calls func_80016B08 with it,
optionally paints a two-colour band (func_80016A60, parameters looked up through func_80031AE8; mode 1 = one full-height
band, mode 2 = split at a row computed from D_80060884/func_8003D2EC), waits for the GPU, records frame times, swaps the
two frame buffers (D_80063450/54/58), VSyncs, starts/stops the root counter by flag 0x200000, sets the display and
draw environments, draws the OT and clears the next buffer.

`best.c` (attempt4): 497/500 on seed 0, 492/500 on seed 1, 1980/2000 on seed 2 with 2000 trials.

after the band block when the mode returned by `func_80031AE8` is neither 1 nor 2 (retail leaves 0 in the delay slot of
the `mode == 2` compare for mode > 2, and stale `$a1` otherwise). A dead scratch register, not behaviour; no C-level way
found to reproduce it. If/else and switch forms of the mode dispatch gave 482 (mode 1 first) and 497 (mode 2 first).
