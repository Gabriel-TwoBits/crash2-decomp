# func_800175D8

Writes a string into a text buffer (text at offset 0xC of arg0). First skips `arg1 >> 8` NUL-terminated strings
already in the buffer to find the start offset. Then copies up to `arg3` bytes from `arg2` until a NUL, mapping each
byte: below 0x20 -> space, then in order `{`->`(`, `}`->`)`, `~`->`{`, `%`->`}`, `&`->`_`. The remaining
`arg3` count is padded with spaces (no terminator written).

Final: attempt1.c, 500 of 500 trials agree on seeds 0 and 1. Nothing disagrees.
