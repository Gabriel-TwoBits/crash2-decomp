# func_800175D8

Writes a string into a text buffer (text at offset 0xC of arg0). Skips `arg1 >> 8` NUL-terminated strings already in
the buffer to find the start offset, then copies up to `arg3` bytes from `arg2` until a NUL, mapping each byte: below
0x20 -> space, then in order `{`->`(`, `}`->`)`, `~`->`{`, `%`->`}`, `&`->`_`. The remaining count is padded with
spaces (no terminator written).

Based on earlier.c. The caller in 800345C8.c passes a fifth argument, so `arg4` was added to the signature (unused by the
function) to make the file landable.

Final: 500 of 500 trials agree on seeds 0 and 1 (248 trials per seed reach the instruction limit and are not compared).
