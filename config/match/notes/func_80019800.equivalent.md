# func_80019800

Takes a slot from a pool: with arg1 == arg2 == 0 it uses `*D_8006CB10` (and stores it in `D_8005F38C`); otherwise
`D_8006CB5C` or `D_8006CBA4` depending on `*D_8006CB58 == 2`. When none is free and arg5 is set, it tries
`func_80018BE4` on up to 8 entries (stride 8 from `D_8006CB18`), frees the result with `func_80019E08` and retries.
No slot: returns -0x16. Otherwise `func_800189CC(slot, arg0)`, state word = 3, `func_80019988`, clears 0x20 bytes at
slot+0x20, returns the result, or the slot when the result < -0xFE.

m2c's `memset(var_s2 + 0x20)` was pointer arithmetic on `s32 *` (0x80 bytes); the asm adds 0x20 bytes.
The asm also sets a1 = 0 before `func_80019E08`; the file's definition takes one argument and the call is written
that way.

Result: 500 of 500 trials agree on seeds 0 and 1.
