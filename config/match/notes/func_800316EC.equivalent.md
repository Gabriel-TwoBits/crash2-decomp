# func_800316EC notes

Reads the ISO9660 volume descriptor (sector 0x10, "CD001"), then the sector at the root record's extent. Walks up to 0x80
path-table-like records, collecting extents of two-character `S<c>` names into a 4-entry table (index `name[1] - '0'`,
unchecked, as in the assembly), reads each listed sector, and walks up to 0x40 directory records (names `.`, `..`, then the
record's own). Names starting with `S`/`s` give a hex-like index from bytes 6-7; byte 11 `D`/`d` updates the 12-byte-stride
entries at D_80069034/D_80069038, otherwise D_8006903C. The buffer is freed with func_800116C0 on every path. The assembly
returns 1/0 in `$v0`, but the declared signature is `void`.

Tried: `earlier.c` (kept as `best.c`): 500/500 on seed 0, 1999/2000 on seed 1 trials. `attempt1.c`: locals grouped in one
struct to mimic the retail frame layout (name at sp+0x10, table at sp+0x30, extents at sp+0x40..0x48); still 1999/2000 on
seed 1 (different trial).

Still disagrees: the unchecked `table[name[1] - '0']` write lands far outside the table (up to 0x190c00 bytes from it, in the
caller's stack), and the retail frame's exact placement relative to it can't be reproduced in C. Not landable: needs every
trial to agree.
