# func_800316EC notes

Reads the ISO9660 volume descriptor (sector 0x10, "CD001"), then the sector at the root record's extent. Walks its path-table-like
records (up to 0x80) collecting extents of two-character names `S<digit>` into a 4-entry table (index unchecked, as in the
assembly), reads each listed sector, and walks its directory records (up to 0x40; names `.`, `..`, then the record's own).
Names starting with `S`/`s` yield a hex-like index from bytes 6-7; byte 11 `D`/`d` updates the 12-byte-stride entries at
D_80069034/D_80069038, otherwise D_8006903C. Frees the buffer with func_800116C0 on every path.

The assembly returns 1 on success and 0 on failure in $v0, but the declared signature is `void`, so the C returns nothing.

Result: 500 of 500 trials agree on seed 0, 499 of 500 on seed 1. The one disagreement is the unchecked `table[name[1] - 0x30]` write landing far outside the table (caller stack above the frame), whose layout the C cannot reproduce. Kept as equivalent.c.
