1. entry at D_80063000 with s16 state (+4) == 1: returns the index;
2. entry at D_80062D70 with s16 state == 0x15: returns the index;
3. first entry whose state (+4) is not 0x14/0x15 and whose byte at D_80062D7B is 0: calls
   `func_80013968(index)` and returns the index; -0xC when none.

`best.c` declares it unprototyped.

loop's state through an `off = 4` variable (8).

entry of loops 2 and 3 the retail sets `$s0`, `$a0`, `$v1` in a different order (s0 first; in loop 3 the `lui/addiu`
of D_80063000 comes after `ori $s0`). Declaration order swap did not change the count.
