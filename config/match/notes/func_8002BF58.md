`arg1->4` against `(temp_s2->4 << 8) - arg0->8->0x34`. When the compare passes and flag 2 is set (and `arg0->0x108 != 2`),
it builds a parameter in `sp18` and calls `func_8001CC10`. Otherwise it updates `arg1->4` and some `arg0` fields. Returns -0xFF.

store to `arg0->0x88`. The m2c structure is otherwise kept as is. Field accesses are raw offsets (struct layouts unknown).
