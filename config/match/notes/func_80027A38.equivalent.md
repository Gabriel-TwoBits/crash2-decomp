# func_80027A38

Initialises the pool: clears the count, buffer, slot table and D_80069358; for modes 2 and 0x3C sets the count to 5,
allocates a 0x1A4-byte slot table (clearing words 2 and 3 of each 0x54-byte slot), then a 5 * 0x1600 + 0x4210 byte
buffer, aligns it to 16 and fills the region pointers. Returns -0xFF on success or for other modes, -0xF when an
allocation fails.

Attempt 1 (earlier.c with the slot stores moved from words 1,2 to 2,3, named constants): 500 of 500 trials agree on
seeds 0 and 1. The count is reloaded each loop iteration, as in the assembly.
