# func_800272A4

Decodes a record (`arg1`) by its top two flag bits, unpacking payloads with `func_80027420` into the buffers held in `arg0`.
Kind 1 unpacks the data at +4 into the +0x38 buffer and returns 0x200. Kind 2 picks a sub-mode from bits 3-5: mode 0
unpacks the data at +1 (when the low 3 bits are nonzero) and returns 0x100; mode 1 unpacks a mask stream (offset read
big-endian from bytes 2-3) and a data stream (+4), passes both to `func_80027500`, and returns 0x100. Anything else returns 0.

Written as one nested `switch`, fields of `arg0` read through offset macros (the file's `Unk800271D8` does not cover them).

Result: `equivalent.c`, 500 of 500 trials agree on seeds 0 and 1. Nothing still disagrees.
