# func_80039C08 notes

Opcode handler: decodes two 12-bit operands from `arg1` (high one `arg1 >> 12`, then the low one). An operand with
0xE00 set is a stack pop (index 0xE1F, `arg0+0xBC` pre-decremented by 4) or a register slot at `arg0 + 0x40 + (v & 0x1FF) * 4`;
otherwise `func_80036D0C(arg0, idx)`. Then it pops two words and calls
`func_80027600(w0, table[w1 >> 8], *dst, *src)`, `table = *(*(arg0+0xC)+0x24)`.
