# func_8002E280

Searches for a free cell near (x, y): returns `depth + 2` with the cell in `*arg3`/`*arg4` when `func_8002DF68` reports a hit
on the start cell, or on one of up to 8 mirrored/swapped offsets from the `D_8005B520` pair table (0x98 pairs); stops early
when the context or the object flags block the search. With no hit, it restarts from (0x10, 0x10) with `depth + 1` if any of
the 0x20 words of `D_8005F3C4` is not -1 (skipped when already at the centre or the object's state kind is 0x22). Otherwise,
below depth 0x100, it flags the object (0x8000), calls `func_8002DFA8`/`func_8002D6E4` and recurses with depth 0x100; else it
sets flag 0x100000, stores 0x10/0x10 and returns 0.

Final: 500 of 500 trials agree on seeds 0 and 1 (first attempt). The m2c draft's `var_v1 += 4` on an `s32 *` was a bug
(the assembly steps one word). Nothing disagrees.
