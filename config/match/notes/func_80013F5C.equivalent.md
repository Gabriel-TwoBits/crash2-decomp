# func_80013F5C

Looks up an entry pointer in the table `D_80067FC4[arg0 >> 1]`. Entry -0x12 means an empty slot: tail-calls `func_80013BD8` with the same arguments and returns its result. Entry -0xFF is reserved: returned as is. Otherwise, if `arg2 & 4`, adds `arg3` to the byte at +0xE; then stores `arg1` at +0x18, adds `arg3` to the byte at +0xF, and returns the entry.

Attempt 1 was the only one needed: 500 of 500 trials agree on seeds 0 and 1 (about 80% end in a shared exception from random pointers, so those compare calls only).
The `func_80013BD8` prototype takes `s8 arg3`, so the compiled call may sign-extend the low byte where the retail one passes the register untouched; the trials do not distinguish them.
