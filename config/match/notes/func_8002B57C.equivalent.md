# func_8002B57C notes

Builds a 6-word box (min x/y/z, max x/y/z) at `arg2 + 0x1020` around the point `arg1`, with the y extents depending on
flags in `arg0->unk_100` (bit 0x40 mode, bit 0x40000000 "big" constants, else the scale at `arg0->unk_08->unk_40`
and `arg3`). It probes every object in `D_8006CB6C` with `func_8002A8D0`, keeping the best hit, then shrinks the box and
calls `func_8003D040`. An optional `func_80027DEC` query (flag 0x20000 in a linked struct) can replace the result with a
bound. The winner gets the 0x80 state bit, `func_8001CC10` is called on a hit between two objects, and the result is
returned (NO_HIT when above the upper bound).
