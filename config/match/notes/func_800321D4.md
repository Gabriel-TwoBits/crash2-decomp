# func_800321D4

Calls func_80031AE8 to look up a value pointer and a descriptor; returns the default (last stack argument) when the lookup
fails, otherwise reads the value as u8/s8/u16/s16/s32 according to the descriptor's byte 4 & 0x1F (1, 17, 2, 18, other).

Matched on the second attempt: 0 of 59 words differ. The first attempt (single `s32 sp28`) gave a 0x38 frame; declaring
`sp28` as `s32 sp28[4]` restored the 0x48 frame.
