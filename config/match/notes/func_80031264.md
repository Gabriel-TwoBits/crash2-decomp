# func_80031264

Matched: `0 of 13 words differ` (`match.c`).

Returns `ratan2(b[0] - a[0], b[2] - a[2]) & 0xFFF`: the 12-bit angle from point `a` to point `b`, using the first and
third words of each (likely X and Z of a 3-word vector, so a heading on the ground plane).

- m2c's draft also scored 0, but passed a spurious third argument to `ratan2` (`$a2` holding `b[0]` is only a scratch
  register). PsyQ's `long ratan2(long y, long x)` with two arguments gives the same bytes.
- `ratan2` is not declared in `include/sdk.h` yet; `match.c` declares it locally.
- Kept the `func_` name: the angle computation is clear, but what the two points are depends on the caller
  (func_80037698), not read here.
