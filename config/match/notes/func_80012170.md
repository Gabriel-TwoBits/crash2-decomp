# func_80012170

Formats a string into the shared buffer `D_8005F414` with `sprintf` and returns it. `a0` selects the format family
(0 or 1; any other value returns -14). `D_8005F1A4` selects between a pair of formats: nonzero prints `a1 >> 4` and `a1`;
zero prints two fixed strings (`D_80010020`, `D_80010038`) and `a1`.

Matched on the second attempt: 0 of 56 words differ. The first (if/else chain) differed in branch layout; a `switch`
with `default` fixed it.
