# func_80013E10

Decrements a signed byte counter at offset 0xF of the object; when it reaches zero and the s16 at offset 0x6 is zero,
calls func_80013F28 and decrements the global D_80067FB0.

Tried: m2c draft (6 of 27 differ: the global was addressed with `lui $at` + `sw`); a local pointer to the global
(same output, optimised away). Declaring the global as an unsized array (`extern s32 D_80067FB0[]`, used as
`D_80067FB0[0] -= 1`) makes GCC load the address into a register first: 0 of 27 words differ.
