# func_8002A3B0

Builds a six-word box at `arg3 + 0x1020` from the position `arg2` (x, y, z) and a scale divisor `arg4`, then calls
`func_8003CD0C(arg0, arg3, arg3 + 0x1008, box, base, arg5, 0xC4653601, func_8002A1B8)`.

- `base` = `arg2.y + D_8005F204`, plus `arg1.y - arg2.y` when that is positive.
- Box words 0..5: x + (-0x9600/arg4) + 0xC80, y - 0x4B00, z + (-0x9600/arg4) + 0xC80, x + 0x9600/arg4 - 0xC80,
  y + height, z + 0x9600/arg4 - 0xC80. `height` is 0x29900 when `arg0->0x100 & 0x40000000`, else `*(arg0->0x8 + 0x40)`.
- Division by zero and INT_MIN / -1 trap in the original; the C divides the same way.

Attempt 1 (from m2c's draft, constants named): 500 of 500 trials agree on seeds 0 and 1. Nothing disagrees.
