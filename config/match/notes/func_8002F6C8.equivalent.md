# func_8002F6C8

Starts a screen/level transition for the object in `arg0`. It bumps a 4-bit usage counter in the `D_80069718` table
(row `arg0[0x30]`, 8 bytes per row, nibble `arg0[0x38]`) and publishes it in `D_8006CDB8`/`D_8006CDB4`. It tears down the
current `D_800608CC` object, copies 0x400 flag words from `arg0 + 0x3C` into `D_8006B1C4` and clears bit 0. It starts
the transition through `func_80014260`/`func_800200A8`, copies 9 words of `arg0` into the `D_8005F38C` object (calling
`func_80019800` first when it is NULL) and resets that object's fields. Finally it updates `D_8006CB84`/`D_8006CD20` and
calls `func_8002F228(0)`. `arg0 == D_800619B8` is the special case that skips the counters and the flag update.

per table row instead of 8 bytes (390/500).

and call comparison reaches few full paths; every branch of the assembly has its counterpart in the C.
