# func_8001C340

Starts an entry on an object: rejects index 0xFF or flag 0x10000000 at +0xAC (-0xE), resolves three 14-bit offsets of the 16-byte table entry into +0xC0/+0xCC/+0xC8, builds the argument stack at +0xBC, calls func_8001C620, then func_8003A014 (0x13) if +0xD0 was set, else pushes a 0 terminator; stores D_8006CB64 at +0xE0 and, when +0xC8 is set and the object is D_8006CB60, calls func_8003A014 (3). Falls through to -0xFF.

Written from earlier.c with named constants; all paths mirrored. Result: 500 of 500 trials agree on seeds 0 and 1 (many end in the same exception from random memory, so the memory comparison is weak there).
