# func_80013888

Finds a slot in the 16-entry table `D_80062D70` (0x2C bytes each), scanning from 15 down to 0: first a slot in state 1,
then one in state 0x15, then one in state 0x14 or 0x15 whose byte at offset 0xB is 0 (calls `func_80013968(i)` on it).
Returns the index, or -0xC when none. `D_80063000 + 4` is `D_80062D70[15].state`, so the C indexes `D_80062D70` throughout.

Final: 500 of 500 trials agree on seeds 0 and 1 (`equivalent.c`).
