# func_80028FE0 notes

Probes an object's position (`arg1`, Y raised by 0x61A8) against the level's list (`D_800608CC->0x10`: count at 0x190,
entries at 0x194, per-entry flags at 0x1B4), then against the table of boxes at `D_8006CB6C + 0x290`, and passes the
resulting id to `func_800289C4` (also for the linked object at +0x44 when `arg2 & 4`).

- Level list: for each entry with flag 4, `func_80014260` then `func_80030D74(entry, pos)`. On the first hit,
  `func_8003DA00(rec, pos, arg2 & 3, <a3 junk>, rec[0..5] << 8)` gives the hit. Loops from scratch while the list is
  not exhausted and the result is null; a result of null with the list exhausted ends with no hit.
- Boxes (`arg2 & 1` = Y mode, else `arg2 & 2` = Z mode): skips the object itself and ids 0xFFFF; box is at +8, or +0x2C
  when `(entry[0] & 7) == 1`. A box containing the start position on the other two axes and the current position on the
  axis is an immediate hit (`pos[axis]` moved to the box edge, hit id read from +0x138). Otherwise the best fallback
  (highest top below the start) is kept and applied after the loop when there is no hit or it is not above the current
  position.
- Id: with a box hit, `hit->0x138` (negative: negated and `arg3` zeroed); with a level hit, bits 4..9 of the hit pointer,
  -1 outside 0x30..0x3F; -1 with no hit.
- The retail function returns the hit pointer in `$v0` (0 on the early return); `include/game.h` declares it `void`
  and the caller ignores it, so the C keeps `void`.
- `func_8003DA00` takes 9 arguments in the assembly but is declared with 3, so it is called through a function-pointer
  cast; `a3` there is leftover register content, `arg3` is passed.
