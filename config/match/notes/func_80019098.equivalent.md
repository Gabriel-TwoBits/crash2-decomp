# func_80019098 notes

Spawns an object into a slot. The handle is `arg0->unk10[arg1 + a + b]` when `arg0->type == 7`; otherwise the retail code
uses the caller's `$s2`. It refuses the handle when its index flags (`D_8006B1C4`) are set, picks a slot (player slot
`*D_8006CB10` for kind 0 or index 1..4, else a free one found by scanning `D_8006CB18` with `func_80018BE4`), initialises
it (`func_80019988`, position, parent, clears 0x20 bytes) and links kind-0x22 objects through `D_8006CDF0/F4/F8`.

`best.c` is the earlier run's C (`earlier.c`), re-scored with equiv.py's new rule that leaves trials depending on
unset registers uncompared: 499 of 500 (seed 0), 498 of 500 (seed 1), 1996 of 2000 (seed 1, 2000 trials).

Still disagreeing: only trials whose `$a1` has bits above 0xFF (e.g. 0x80103dbc). The retail code adds `$a1` unmasked
(`addu $v1, $a1, $v1`), the C masks the `u8` parameter, so the faulting address differs. The prototype is fixed as `u8`
and callers pass a u8, so no valid input is affected. No `equivalent.c`: not every trial agrees on landing's check.
