# Nsf_PageOut (func_80012A20)

Pages a slot out: clears `D_80067FB4[0]` if it holds the slot; for state 0x14/0x15 with a page type other than 1, 3 or 4,
walks the page's entries, finds each entry's record in the `D_80067590` bucket by EID, calls the type's handler from
`D_8005B1EC` (stride 0x1C) and stores the slot's index into the record, then calls `Nsf_FreePageSlot`. Types 1/3/4 write
-0x12 into `D_80067FC4[idx >> 1]` and fall to the idle path (state 1, bytes 0xE/0xF cleared). Returns -0xFF.
