# func_80035E7C

Checks the state table: if `D_8005F264[2] >= 15`, walks `D_8005F264[8]` entries of 0x28 bytes starting at byte offset 0x49C,
calling `func_80035F00` on each; returns at the first nonzero result, otherwise calls `func_80036084(0x40)`.

Matched on the 4th attempt, 0 of 33 words differ. A `for` loop with `(char *)D_8005F264 + 0x49C + i * 0x28` gives the
original's strength reduction; `do`/`while` and manual offset variables gave the wrong registers and frame size.
`D_8005F264` is defined in the file (`s32 *`), as the `$gp` access requires.
