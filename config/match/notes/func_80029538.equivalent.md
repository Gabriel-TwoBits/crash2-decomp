# func_80029538

Builds a bounding box (six words at offset 0x1008 of `c`: `a` +/- 0x12C00, Y adjusted by half of `b->sub->unk_40`
unless `b->flags` has 0x40000000), then walks the slot list at `*(D_800608CC + 0x10)`. For each slot with bit 4 set it
fetches an entry via `func_80014260`, tests it with `func_80030E1C` against the box, and on success `func_8003BF90`
appends to the 8-byte-entry list at `c` and returns the new count (stored at 0x1004). The list ends with a 0xFFFF halfword.

The retail code also leaves the count in `v0`, but `game.h` declares the function `void`, so the C keeps `void`.

Result: 500 of 500 trials agree on seeds 0 and 1 (attempt1.c = equivalent.c). Most trials end in the same exception.
