# func_80012250

Reads a word from the object; if its low two bits are set it is not a pointer, so it returns func_80012010(arg0[1]); otherwise treats the word as a pointer and returns its field at offset 8.

Matched (0 of 17 words differ) on the second attempt. The first, with two early returns, put the load before the call; a single result variable assigned in if/else gives the retail layout.
