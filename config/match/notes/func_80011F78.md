# func_80011F78

Packs up to 5 characters of a NUL-terminated string into a 31-bit key: each character becomes its index (0x00-0x3F) in the
table `D_8005B198`, or 0x3E when absent. A NUL ends the string and the remaining slots are filled with 0x3E. The result is
`(acc << 1) | 1`.

Best: `best.c`, 35 of 38 words differ (baseline 36). The control flow lines up (same branches, loop shapes and delay slots).
The only difference is register allocation: the compiler gives `n` to `$a2`, the accumulator to `$t0` and the character to
`$a3`; the retail code has accumulator `$a2`, counter `$a3`, character `$v0` copied to `$t0`.

Tried (a1-a7): return inside the loop vs `break`, `while (n-- != 0)` vs `--n` for the fill, init order, declaration
order (acc/n first, locals reversed), m2c's shape with separate temps. None changed the register assignment.
Not run: decomp-permuter.
