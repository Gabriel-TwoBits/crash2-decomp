# func_80022A5C

Camera-style transition step. Reads a 3-word path argument, snapshots the current state (`D_800608CC`, `D_800608D4`,
`D_800608E0`, `D_8005BAE4`) and builds the next state from the object returned by `func_80014260`. `func_8002433C`
returns a sign (and distances); `func_80024658` picks the mode when it is non-zero. With a countdown `D_8005BA14`
non-zero, it interpolates `D_800607F4..FC` toward the target position (10-bit fixed point), decrements the countdown,
and fires the finish event (`D_8005B994 = 5`, `func_80023084`) when it reaches 0. With the countdown at 0 it applies
the final step and fires the finish event only if `D_800608D4` equals the target.

Locals sit in a struct laid out as the retail frame, so the tester sees the same stack contents behind out-pointers.
Result: 500/500 on seeds 0 and 1, 2000/2000 on `--trials 2000`. Most trials end in the same exception (callee-made
values), so only about 80 per seed compare memory.
