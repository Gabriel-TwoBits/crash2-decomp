# func_80018BE4

Recursive tree walk. For a node (`arg0`) whose type word is not 2, it calls the callback `arg1(node, arg2)` and returns
a non-zero result at once. It then takes the child list head (`+4` when the type is 2, `+0x4C` otherwise) and visits
each child, linked through `+0x48`, recursively, stopping at the first non-zero result. A NULL node returns 0.

Matched on the first attempt (`attempt1.c`, copied to `match.c`): 0 of 50 words differ. The probe needs a
self-contained file, so `attempt1.c` carries its own typedefs; `match.c` uses the project headers.
