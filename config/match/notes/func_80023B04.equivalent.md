# func_80023B04

Reads a keyframe pair from an animation lookup and writes two fixed-point (<<8) values to `*arg1`/`*arg2`.
`key` (D_800608F0, or func_800321D4 query 0x29) selects the blend table (D_8005BA28, or +6 words when key is 0);
keys 0/3/4/10 interpolate between the s16 pairs at p[0..1] and p[2..3] by table word 3 (0 = none, 0x400 = full,
else linear >> 10); other keys take p[0..1]. The lookup func_80031AE8 is retried with the fallback entry when it returns 0.

Final: attempt1.c (from earlier.c, with D_800608D4[0] and named constants) = equivalent.c. 500 of 500 trials agree on seeds 0 and 1.
About 90% of trials end in the same exception (calls compared, not memory), so the later paths are less exercised.
The jump-table case grouping comes from m2c's reading of jtbl_80010438 and was not checked word by word.
