# func_80022224

Stores its argument in D_800608FC. If D_800608D4 and D_800608CC are both non-zero, it calls func_800321D4 (D_800608D4, 0x173, 0, 0, 0, 2, 0), multiplies the result by 3 to get a slot, and indexes the table at D_800608CC.
The index is slot + the word at 0x184 in the sub-table at table+0x10, and each entry is 4 bytes.
D_800608D8[0] gets the word at entry+0x14.
D_800608DC gets that same value when arg0 == 1, otherwise the word at entry(slot + arg0)+0x10.

Written plainly in one go (equivalent.c). The final count is 500 of 500 trials on seed 0 and on seed 1. About half of the trials end in the same exception, so memory is not compared there.
Nothing disagrees.
