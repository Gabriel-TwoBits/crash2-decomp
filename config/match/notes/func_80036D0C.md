# func_80036D0C

Resolves an operand/slot descriptor `arg1` against an object `arg0` and returns a pointer:
bit 0x800 clear: `*(arg0->[0x10 or 0x14 by bit 0x400] + 0x18) + (arg1 & 0x3FF) * 4`;
bit 0x800 set: bit 0x400 picks a pointer table at `arg0 + 0x40 + ((arg1 >> 4) & 0x1C)` (NULL if empty);
0x200/0x100/0x80 select `arg0->0xC4 + signed field`, special values 0xBE0 (NULL) / 0xBF0 (1),
or one of two scratchpad slots (0x1F800040, flipped by `D_8005F290`) holding a sign-extended immediate.
