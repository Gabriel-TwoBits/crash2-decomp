# func_800254D4 notes

Walks a path (points from `func_80031AE8`, count from `func_800322C0`) starting at the 8.8 fixed-point position in
`arg0+8`, looking for where a projected distance (planar via `arg3`/`arg4`/`arg5`, else the Y delta) reaches `arg2`.
Forward when `arg0+0xC == 2`, else backward. On crossing the target it interpolates inside the segment (returns 0,
position in `*arg6`); otherwise it keeps the closest position, giving up with -1 after 3 steps that get no closer; the
path end returns the best distance.

Tried: earlier.c (499/500, 495/500 on seed 0). Its remaining disagreements were loads of all three axes of both points
up front; retail reads only X/Z (planar) or Y. attempt2.c reads only the axes in use: 500 of 500 on seeds 0 and 1.
Helpers are macros because a static function would add a recorded call.
