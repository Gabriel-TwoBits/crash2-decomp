# func_800254D4

Walks a path (points fetched with `func_80031AE8`, count from `func_800322C0`) from the position in `arg0+8`
(8.8 fixed point, index in the high bits) looking for where a projected distance (planar via `arg3`/`arg4`/`arg5`,
else the Y delta) reaches `arg2`. Forward when `arg0+0xC == 2`, otherwise backward. It interpolates inside the
segment when the target is crossed (returns 0, position in `*arg6`), keeps the closest position otherwise, and gives
up with -1 after 3 steps that do not get closer; the path end returns the best distance.

Tried: attempt1 (from m2c's draft, restructured). Helpers had to be macros: a static function adds a recorded call.

different addresses (load order only); no disagreement on a non-faulting path was seen.
