`func_80036D0C`. It also decodes a condition register, where index 0x1F pops the stack. It clears flag 0x20000.

If the condition word and the source pointer are both nonzero, it copies up to 7 stack words below the stack pointer
into a buffer and calls `func_8001D194` (source value, mode, count, buffer). Otherwise it clears the result field (0xD4).

- With the flag set and `arg2 & 2` set, it returns -0xFF.
