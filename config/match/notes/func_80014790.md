# func_80014790

Walks the two 0x2C-byte entry tables (D_80067950, D_800675B0). For every entry whose state is not 1 and whose byte at +0xF is
nonzero, it tests the entry's id (`+0x14 >> 1`) against a bitmask passed in `arg0`, and calls func_80013EB0 when the bit is clear.

Matched: 0 of 98 words differ (`./score.sh match.c`).

Tried: m2c form (18-20 differing words), `idx` temporaries (18), then the permuter found that loading the mask word into a
separate local before the test restores the `lw`/`sll` order. Both loops need their own local (`word0`, `word`), declared in
that order; sharing one local leaves 2 words differing.
