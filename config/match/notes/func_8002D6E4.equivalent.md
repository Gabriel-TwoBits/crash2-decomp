# func_8002D6E4

Collision broad phase against the object list `D_8006CB6C`: for each entry whose box (entry+8, or entry+0x2C for
non-zero shape kinds) overlaps the widened query box, optionally clears the object's bucket bit in the 32x32 grid
`D_8005F3C4`, walks the shape's border cells (kind 0: `func_8002CB68`/`func_8002CB1C`; kind 1: `func_8002CC50`), and
calls `func_8001A710` when the bucket was already marked. Finally ORs the saved bits back into the row.

Attempts: attempt1.c, written from the assembly and m2c's draft. First versions disagreed on (1) a `static` helper
that GCC 2.7.2 does not inline (extra call), (2) a do-while where the loop test is `n > 0` (signed), (3) an early
dereference of the object's shape pointer that the original reaches only after earlier tests. All fixed.

Final: 500 of 500 trials agree on seeds 0 and 1; also checked at 2000 trials (see above run). About 84% of trials end
in the same exception, so those are compared by calls only.
