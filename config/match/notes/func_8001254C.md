# func_8001254C

Relocates a loaded archive in place: header magic `0x1234` at +0 (else returns -0x12), an early return of -0xFF when the
halfword at +2 is 1. The u32 table at +0x10 (count at +8, inclusive) holds offsets that become pointers (base + offset);
each entry has its own table at +0x10 (last index at +0xC) of offsets rebased onto that entry. Returns -0xFF on the
relocation path as well.

Result: matched, `./score.sh match.c` reports `0 of 43 words differ`.

Attempts: plain C (8 differ) -> `(j * 4) + ptr` forms and a hoisted `entry + 0x10` temporary (5) -> `table` loaded
before `count` (2) -> decomp-permuter (3 min) found the last two operand-order swaps: `table - (-i)` and `data - (-j)`.
Those two forms are needed for `addu` operand order; plain `table + i` / `data + j` leave 2 words differing.
Not run in the build (`ninja` / probe_compiler); the landing step must check the SHA-1.
