# func_80031578

Seeded PRNG: `seed = seed * 0x41C64E6D + 0x3039` (D_8005F224, `$gp`), then `(u32)seed / 15 % 0x7FFFFFF`, and returns
that value modulo `arg0` (0 when `arg0 == 0`). The `v < 0` branch is dead in practice but kept for the bytes.

Matched: `./score.sh` reports 0 of 56 words differ (attempt 4). Needed: a `seed` temporary, `u32 q`, `s32 v`,
single `r` result, and the `v >= 0` branch first.

Caveat: `include/game.h` declares `void func_80031578(s32);`, which conflicts with the real `s32` return
(callers' v0 is set). match.c omits `game.h` for that reason; the prototype should become `s32 func_80031578(s32);`.
