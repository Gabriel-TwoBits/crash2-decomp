# func_80022E74

Copies three words from `arg0` to a stack buffer. If byte `D_8005B99B` is set, calls `func_80014260(&D_8005B99B + 0x13D, 1, 0)`
-> `p`, then `func_800200A8(p, p[4 + D_8005BADC * 3 + p->unk_10->unk_184], D_8005BAE0, 0)`, sets `D_8005B994 = 5` and
stores `D_800608CC` at word 6 of the block `D_8005F38C` points to. Otherwise calls
`func_800200A8(D_800608CC, D_800608D4, D_800608E0, 0)` and `func_800231B0(copy)`.

Written once from the assembly and m2c's draft: 500 of 500 trials agree on seeds 0 and 1. Nothing disagrees.
Note: `D_8005F38C` is declared `s32` in game.h, so it is cast to a pointer for the store.
