# func_8003817C

Interpreter step for a script-like instruction word (`arg1`) on an object: decodes a destination register (bits 12-14),
a source operand (immediate slot, stack pop or `func_80036D0C` lookup), and dispatches on bits 18-20 to eight operations
(call `func_8001F054` on the vector, scale by sin/cos, blend two vectors, animation-vertex lookup, normalise, clear).

Built from m2c's draft with named constants and a byte-offset view of the object (its layout is unknown).
`attempt1.c` agrees on 500/500 (seeds 0 and 1) and 3000/3000 (seed 2); copied to `equivalent.c`.
About 40% of trials end in the same exception (null source), so the animation and normalise paths are covered by the
other trials only; both were written branch by branch from the assembly.
