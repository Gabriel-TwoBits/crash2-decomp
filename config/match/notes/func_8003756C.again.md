# Gool_OpEntityFieldValue (func_8003756C)

Resolves two operands encoded in `arg1` (high and low 12 bits): a reference of 0xE00-class is either a stack pop/push
(`0xE1F`, via `sp`) or a `links[]` slot, anything else goes through `Gool_ResolveRef`. The first operand is read and its
value `>> 8` is the property id; the second is the destination. When the destination and `entity` are non-null, it stores
`Ent_GetPropertyValue(entity, id, 0, 0, 0, 2, 0)`, else 0.
