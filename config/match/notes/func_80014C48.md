# func_80014C48

Matched: `match.c`, 0 of 8 words differ (`./score.sh match.c`, GCC 2.7.2).

## What it does

Returns `D_8005F188 - (D_8005F184 - 0x80000000)`: the distance from `D_8005F184`, taken as a KSEG0 address with the
segment bit stripped, to `D_8005F188`. No callers found, so the purpose of both words stays unnamed.

## What was tried

- m2c's draft, one expression: 6 of 8. The `lui 0x8000` is scheduled first and the last `subu` has its operands swapped.
- A temporary for `D_8005F184 - 0x80000000`, or locals for both loads then `a -= 0x80000000`: 5 of 8. The operands line
  up; only the `lui 0x8000` is still hoisted above the two loads.
- Pointer types (`u8 *`) and reassociated forms (`b - a + C`, `b + (C - a)`): 6 of 8.
- decomp-permuter on the 5-of-8 version found a 0 in seconds by wrapping `a -= 0x80000000` in `do { } while (0)`. The
  loop notes act as a scheduling barrier, so the `lui` stays after the loads, as in the retail code. The original likely
  went through a macro built that way. A plain extra temporary without the loop does not match (5 of 8).
