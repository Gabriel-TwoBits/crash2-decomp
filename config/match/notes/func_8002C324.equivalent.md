# func_8002C324

Allocates a box (0x20 bytes, or 0x44 for kind 1) from a pool below `D_8006CB6C`, registers it in the pool's pointer
list and fills it with an object's bounds: from the object's position and scale when no slot is given (`idx < 0`), from
the slot's stored box plus a `func_800309A8` transform for kind 1, or from the rotated slot extents (`func_8001E8E4`
unless the object is unrotated at scale 0x1000) for kind 0, with a final offset when `D_80062AD8 & 0x200` and the
`D_8005F38C` flag is set.

Third argument is the slot index (`$a2`; m2c's draft dropped `arg1`). `-2` becomes slot 0 when the byte at object+0xE8 is 1.

Result: 500 of 500 trials agree on seeds 0 and 1. The first attempt agreed on 491; the rest were the callee's output
buffer (`pos`) reading uninitialised stack, which only lines up with the retail frame when the locals are arrays in the
retail order (pos at 0x18, in at 0x28, ext at 0x38).
