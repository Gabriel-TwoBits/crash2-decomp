# func_800270C4

Moves a cursor held in `arg0[0]` (fixed point, 8 fractional bits) to `arg1`, clamped to `[0, arg0[1])`. It advances by the
whole-unit difference through `func_800271D8`, and calls `func_8002719C` first when the start or the delta is negative.
It returns the OR of the callees' results.

Result: matched, 0 of 54 words differ (`./score.sh match.c`). The first draft differed only in an s0/s1 swap (18 words);
decomp-permuter closed it in under 5 minutes by making `delta = end - pos` an unconditional statement after the clamp
`if` instead of a second assignment inside it.

`func_8002719C` and `func_800271D8` return `s32` (both results are used) but BRIEF.md lists them as `void`; `match.c`
declares them with `s32` returns.
